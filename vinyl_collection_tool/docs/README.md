# PlantUML Diagrams

This folder contains PlantUML diagrams for the project. Place all `.puml` files here.

## How to Render Diagrams

1. **Install PlantUML**
   - You can use the PlantUML extension for VS Code (recommended) or install PlantUML locally with Java.
   - For VS Code: Install the "PlantUML" extension by jebbs.
   - For CLI: Download PlantUML jar from https://plantuml.com/download and run with Java.

2. **Render Diagrams**
   - Open a `.puml` file in VS Code and use the PlantUML extension to preview or export.
   - Or, from the command line:
     ```sh
     java -jar plantuml.jar your_diagram.puml
     ```

3. **Example Diagram**
   See `erd.puml` in the `design` folder for a template.
